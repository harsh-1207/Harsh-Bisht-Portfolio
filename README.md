# Harsh Bisht — Portfolio

Updated portfolio based on the current CV, designed for GitHub Pages.

## Run locally

```bash
npm install
npm start
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

The existing `homepage` setting is preserved.

## Contact form

The contact form is intentionally backend-free. `public/index.html` contains a small `sendPortfolioMessage` script that opens the visitor's default email client with the name, reply email and message pre-filled to `harshbisht113322@gmail.com`.

## Resume

The current CV is included at `public/Harsh_Bisht_CV.pdf` and linked from the header and hero section.
